## The entry

> A fridge light that files a formal complaint whenever you open the door just to stare, then dims itself in protest until you apologise and commit to a snack.

The program (`main.ts`, Node 22) writes that single sentence to `/output/entry.txt`.
It is deterministic: no randomness, no clock, no network, no environment input —
every run produces the exact same bytes.

## Run

```sh
node main.ts
cat /output/entry.txt
```
